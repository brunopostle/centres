# Reference sources

## `salingaros-2025-fifteen-properties.pdf`

Nikos A. Salingaros, appendix from *"Living geometry, AI tools, and Alexander's 15
fundamental properties"*, **Frontiers of Architectural Research** 2025, 14(6),
1491–1515. <https://doi.org/10.1016/j.foar.2025.01.002>. Open access, CC BY-NC-ND.

A detailed expansion of each of Alexander's fifteen properties, written explicitly
for the purpose of programming software to detect them in an image.

**This is the authority this project previously lacked.** `THEORY.md` had stated
several constants as Alexander's with no citation — a child-area coverage of 0.65,
a radial band of 0.3–0.7, a scale-ratio range of 2–4 — and `AUDIT.md` §11 flagged
them as invented and attributed. Where this source states a figure, it supersedes
those. Where it does not, no figure should be attributed to Alexander at all.

See `AUDIT.md` §15 for a property-by-property comparison of what this source says
against what the code computes.
